# رحلة البرمجة

مستودع تعلّمي من الصفر حتى أصبح مبرمجاً حقيقياً: Python، ثم الويب، ثم React، ثم الباك آند، ثم تطبيقات الذكاء الاصطناعي، ثم الإطلاق والمراجعة الاحترافية.

## التطبيق

**[حمّل آخر نسخة من تطبيق أندرويد](https://github.com/ayachzawi/python-journey/releases/latest/download/python-journey.apk)**

التطبيق يقرأ هذا المستودع مباشرة. كل حل ترفعه يُصحَّح تلقائياً، ويظهر في التطبيق نقاطاً ومستويات وسلسلة أيام وشارات. وكل درس جديد يُضاف إلى `content/roadmap.json` يظهر في التطبيق دون تحديث.

## كيف تعمل كل يوم (من الجوال)

1. افتح التطبيق، ثم «افتح في المحرر» من مهمتك التالية.
2. اقرأ المهمة، واكتب حلك في تبويب «الكود».
3. «تشغيل» لترى ما يطبعه برنامجك، ثم «اختبار» لتشغيل الاختبارات على جوالك.
4. «إرسال»: يرفع حلك إلى هذا المستودع، فيصحّحه GitHub Actions وتصلك النقاط خلال دقيقة.

قبل أول إرسال: اربط GitHub مرة واحدة من تبويب «الأدوات» ← «ربط GitHub».

<details><summary>من الحاسوب</summary>

```bash
git pull                                  # اسحب آخر تحديث (البوت يحدّث progress.json)
pytest exercises/p1/t01-variables         # شغّل الاختبار عندك
git add . && git commit -m "حل تمرين المتغيرات" && git push
```
</details>

## بنية المستودع

| المسار | ما فيه |
|---|---|
| `content/roadmap.json` | الخريطة: المراحل والخطوات وطريقة التحقق من كل خطوة والنقاط |
| `exercises/` | التمارين: لكل تمرين README واختبارات، وأنت تكتب `solution.py` |
| `journal/` | دفتر التعلم اليومي (ملف .md لكل يوم) |
| `projects/` | مشروع كل مرحلة في مجلد خاص فيه README.md وكود |
| `reviews/` | تقارير مراجعة الكود لكل مرحلة |
| `progress.json` | يولّده GitHub Actions تلقائياً بعد كل push، لا تعدّله يدوياً |
| `scripts/build_progress.py` | السكربت الذي يفحص المستودع ويبني progress.json |
| `app/` | كود تطبيق أندرويد (Expo / React Native) |

## كيف يُحسب التقدم

- **تمرين:** ينجح عندما تنجح كل اختباراته في GitHub Actions.
- **مشروع:** مجلده موجود وفيه `README.md` وملف كود واحد على الأقل.
- **مراجعة:** ملف `reviews/pX.md` فيه 300 حرف على الأقل.
- **دفتر التعلم:** عدد ملفات `.md` في `journal/`.
- **خطوات يدوية:** تؤشّر عليها بنفسك من داخل التطبيق.

## القواعد

1. 60 إلى 90 دقيقة يومياً، 5 أيام في الأسبوع.
2. في المراحل 0 إلى 2: الـ AI معلّم فقط. لا تنسخ منه كوداً جاهزاً.
3. لا تنتقل لمرحلة قبل إنهاء مشروعها وتمرين المراجعة.
4. لا ترفع كلمات مرور أو مفاتيح API أو بيانات خاصة. هذا المستودع عام.
