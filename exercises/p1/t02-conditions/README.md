# التمرين 1.2: الشروط

اكتب الدالة `grade(score)` التي ترجع التقدير حسب الدرجة من 100:

| الدرجة | التقدير |
|---|---|
| 90 إلى 100 | ممتاز |
| 80 إلى 89 | جيد جداً |
| 70 إلى 79 | جيد |
| 50 إلى 69 | مقبول |
| أقل من 50 | راسب |

وإذا كانت الدرجة أقل من 0 أو أكبر من 100 ترجع `غير صالح`.

انتبه للحدود: 90 بالضبط تقديرها ممتاز، و89.5 تقديرها جيد جداً.

**شغّل الاختبار:**

```bash
pytest exercises/p1/t02-conditions
```

اكتب حلك في `solution.py` داخل هذا المجلد. عندما تنجح كل الاختبارات عندك، ارفع الحل إلى GitHub وسيظهر تقدمك في التطبيق تلقائياً.

إذا علقت، استعمل برومبت **تلميح** ولا تطلب الحل كاملاً.
