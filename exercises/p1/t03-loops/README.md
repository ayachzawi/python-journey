# التمرين 1.3: الحلقات

اكتب ثلاث دوال:

1. `sum_even(n)`: مجموع الأعداد الزوجية من 1 حتى n (شاملة n). مثال: `sum_even(10)` ترجع 30.
2. `countdown(n)`: ترجع قائمة تعدّ تنازلياً من n إلى 1. مثال: `countdown(3)` ترجع `[3, 2, 1]`.
3. `table(n)`: ترجع قائمة من 10 نصوص لجدول ضرب n، شكل كل نص: `3 x 4 = 12`.

استعمل `for` في واحدة على الأقل و`while` في واحدة على الأقل.

**شغّل الاختبار:**

```bash
pytest exercises/p1/t03-loops
```

اكتب حلك في `solution.py` داخل هذا المجلد. عندما تنجح كل الاختبارات عندك، ارفع الحل إلى GitHub وسيظهر تقدمك في التطبيق تلقائياً.

إذا علقت، استعمل برومبت **تلميح** ولا تطلب الحل كاملاً.
