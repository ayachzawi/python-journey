# التمرين 1.4: الدوال

اكتب دالتين:

1. `apply_discount(price, percent=10)`: ترجع السعر بعد الخصم. إذا لم يُعطَ الخصم يكون 10%.
2. `split_bill(total, people, tip=0)`: تضيف نسبة البقشيش `tip` (بالمئة) إلى الفاتورة، ثم تقسمها على عدد الأشخاص، وترجع نصيب الشخص مقرّباً لرقمين عشريين. إذا كان عدد الأشخاص 0 أو أقل ترفع `ValueError`.

**شغّل الاختبار:**

```bash
pytest exercises/p1/t04-functions
```

اكتب حلك في `solution.py` داخل هذا المجلد. عندما تنجح كل الاختبارات عندك، ارفع الحل إلى GitHub وسيظهر تقدمك في التطبيق تلقائياً.

إذا علقت، استعمل برومبت **تلميح** ولا تطلب الحل كاملاً.
