# التمرين 1.5: القوائم والقواميس

اكتب دالتين:

1. `top_clients(payments, k)`: تستقبل قائمة دفعات، كل دفعة قاموس مثل `{"client": "أحمد", "amount": 200}`. اجمع دفعات كل عميل، ثم ارجع أسماء أعلى k عملاء مرتبة من الأعلى دخلاً إلى الأقل.
2. `word_count(text)`: ترجع قاموساً فيه كل كلمة وعدد مرات ظهورها (الكلمات مفصولة بمسافات).

**شغّل الاختبار:**

```bash
pytest exercises/p1/t05-collections
```

اكتب حلك في `solution.py` داخل هذا المجلد. عندما تنجح كل الاختبارات عندك، ارفع الحل إلى GitHub وسيظهر تقدمك في التطبيق تلقائياً.

إذا علقت، استعمل برومبت **تلميح** ولا تطلب الحل كاملاً.
