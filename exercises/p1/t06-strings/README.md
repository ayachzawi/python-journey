# التمرين 1.6: النصوص

اكتب ثلاث دوال:

1. `is_palindrome(s)`: ترجع True إذا كان النص يُقرأ نفسه من الجهتين، مع تجاهل المسافات وحالة الأحرف. مثال: `"Never odd or even"` ← True.
2. `slugify(title)`: تحوّل عنواناً إنجليزياً إلى رابط: أحرف صغيرة، والمسافات تصبح `-`، وتُحذف المسافات الزائدة في الأطراف. مثال: `"  My First App "` ← `"my-first-app"`.
3. `remove_tashkeel(text)`: تحذف التشكيل العربي (الفتحة والضمة والكسرة والسكون والشدة والتنوين). تلميح: هذه الحركات رموزها من `\u064B` إلى `\u0652`.

**شغّل الاختبار:**

```bash
pytest exercises/p1/t06-strings
```

اكتب حلك في `solution.py` داخل هذا المجلد. عندما تنجح كل الاختبارات عندك، ارفع الحل إلى GitHub وسيظهر تقدمك في التطبيق تلقائياً.

إذا علقت، استعمل برومبت **تلميح** ولا تطلب الحل كاملاً.
