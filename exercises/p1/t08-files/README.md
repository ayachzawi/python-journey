# التمرين 1.8: الملفات وJSON

اكتب دالتين لحفظ قائمة مهام وقراءتها:

1. `save_tasks(path, tasks)`: تحفظ قائمة المهام في ملف JSON، بترميز UTF-8، وبحيث يبقى النص العربي مقروءاً داخل الملف (ابحث عن `ensure_ascii`).
2. `load_tasks(path)`: تقرأ المهام من الملف. إذا لم يكن الملف موجوداً ترجع قائمة فارغة بدل أن تتوقف.

استعمل `with open(...)` في الدالتين.

**شغّل الاختبار:**

```bash
pytest exercises/p1/t08-files
```

اكتب حلك في `solution.py` داخل هذا المجلد. عندما تنجح كل الاختبارات عندك، ارفع الحل إلى GitHub وسيظهر تقدمك في التطبيق تلقائياً.

إذا علقت، استعمل برومبت **تلميح** ولا تطلب الحل كاملاً.
