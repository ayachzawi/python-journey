# التمرين 1.9: الوحدات وpip وvenv

هذا التمرين عن تنظيم الكود في ملفات:

1. أنشئ داخل هذا المجلد مجلداً اسمه `utils` وفيه ملفان: `__init__.py` (فارغ) و`money.py`.
2. في `money.py` اكتب الدالة `format_usd(amount)` التي ترجع المبلغ بصيغة `$1,234.50`.
3. في `solution.py` استورد الدالة: `from utils.money import format_usd`، واكتب الدالة `report(amounts)` التي ترجع مجموع المبالغ بنفس الصيغة.
4. أنشئ `requirements.txt` في هذا المجلد فيه سطر واحد: `pytest`. هذا الملف يخبر أي شخص بالمكتبات التي يحتاجها مشروعك.

في المحرر تضيف الملفات بزر **+** فوق الكود، واكتب المسار هكذا: `utils/money.py`.

**لاحقاً على الحاسوب:** ستتعلم البيئة الافتراضية: `python -m venv .venv` ثم `pip install -r requirements.txt`.


**طريقة العمل في التطبيق:** اكتب حلك في `solution.py` من تبويب «الكود»، واضغط «تشغيل» لترى ما يطبعه، ثم «اختبار». عندما تنجح كل الاختبارات اضغط «إرسال»، وتصلك النقاط خلال دقيقة.

إذا علقت، استعمل برومبت **تلميح** ولا تطلب الحل كاملاً.
